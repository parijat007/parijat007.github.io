# Watchfloor brand assets

The mark: a 3×3 floor of tiles with the top-right one lit red. Out of everything screened, the one item
that needs action. Original design; red (`#F0283C`) is the same colour the site reserves for confirmed
exploitation, so it never decorates.

| File | Use |
|---|---|
| `watchfloor-mark.svg`, `watchfloor-mark-{16…1024}.png` | Default: dark tile, any size |
| `watchfloor-mark-light.svg`, `watchfloor-mark-light-1024.png` | On white or light backgrounds |
| `watchfloor-mark-transparent-dark-ui.svg` / `-light-ui.svg` | Tiles only, no background |
| `watchfloor-avatar.svg`, `watchfloor-telegram-avatar-640.png` | Round crops (Telegram, LinkedIn page): grid inset to stay inside the circle |
| `favicon.ico` | 16, 32 and 48 px |

Colours: tile `#121823`, ground `#0B0F15`, cells `#364259`, signal `#F0283C` (light version: `#FFFFFF`,
`#D5DBE5`, `#D41B2F`). Wordmark: Archivo Bold at 118% width. Keep clear space of one tile on every side;
never recolour the red tile or move it.
